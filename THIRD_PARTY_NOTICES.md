- **libvips** (`@img/sharp-libvips-*`, LGPL-3.0-or-later): prebuilt shared library installed with `sharp`, an optional dependency of `next`. Used unmodified and dynamically linked; it can be replaced by installing another build of the package. The web app does not use `next/image`, so it is not loaded at run time. Source: https://github.com/libvips/libvips, build: https://github.com/lovell/sharp-libvips.
- **caniuse-lite** (CC-BY-4.0): browser-support data by the Can I Use contributors (https://caniuse.com), packaged by https://github.com/browserslist/caniuse-lite. Read at build time.

Their licence texts ship inside the AI image, in `pypdfium2-*.dist-info/licenses/`.
- **pdfjs-dist** (Apache-2.0): the web bundles pdf.js and its worker. The package's CMap and standard-font data folders are not served by the app.
