## Dòng CV nháp (T8.4 sẽ rà lại; bạn tự dán vào CV)

Dạng: làm gì → bằng gì → kết quả đo được. Chỉ giữ dòng nào bạn bảo vệ được 15 phút.

- Built a multi-tenant invoice extraction app (Next.js, NestJS, FastAPI, PostgreSQL RLS, BullMQ, Keycloak): XML parsed exactly, PDFs and photos read by a vision LLM, then schema-validated, rule-checked and human-approved.
- Designed an evaluation on a fixed 100-invoice synthetic set and chose the model by a rule fixed before the runs: 93/100 invoices with all critical fields right, 0 of 24 prompt-injection attempts succeeded, $0 paid (free tier).
- Enforced tenant isolation with PostgreSQL Row-Level Security under the app filter, covered by integration tests against a real database in CI.
- Shipped a read-only production build (Docker, Caddy): writes blocked by a guard and a read-only transaction, no LLM reachable.
- Worked with an AI coding agent under a spec → plan → evidence → independent review → comprehension-gate loop, and documented the mistakes it caught.
