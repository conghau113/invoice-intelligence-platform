## Khái niệm học được
- **Idempotency**: `documents.service.ts:76-137`: gửi lại cùng request cho cùng kết quả, không tác dụng phụ thứ hai. Ở đây key bắt "cùng request" (`:88`, `:116`).
- **Unique constraint vs Idempotency-Key**: unique (`schema.ts` `documents_tenant_hash_unique`, `documents.service.ts:101`) bảo vệ dữ liệu theo nội dung, mọi key; key (`schema.ts:117`) bảo vệ theo request và trả đúng response cũ, bắt dùng sai key (`:144`, 422). Cần cả hai.
- **At-least-once**: client/hàng đợi có thể gửi lại; hệ thống phải chịu được. `created` (`documents.service.ts:106`) cho T2.4 biết chỉ enqueue một lần.
- **Cạnh tranh song song với `ON CONFLICT DO NOTHING`**: request thứ hai chờ commit của request đầu rồi không làm gì, đọc lại dòng thắng (`:119-124`).
- **Transaction ngắn**: `skip-tenant-transaction.decorator.ts` + `tenant-transaction.interceptor.ts:29-33`: I/O chậm không giữ connection.

## Review (code-reviewer)
Không có mục Cao. Đã sửa:
- **Vừa:** `create` xoá file cả khi lỗi xảy ra *sau* COMMIT (ví dụ mất kết nối lúc nhận ack) → document đã commit mất file. Nay chỉ xoá khi chắc chắn đã rollback (`created=false` hoặc 422); lỗi khác giữ file cho job dọn (`documents.service.ts:66-78`). Test `commit-then-fail` ở `test/documents-create.int-spec.ts`; drill "luôn xoá" → đỏ.
- **Vừa:** luồng "gửi 2 lần → 1 bản ghi" mới được chứng minh ở mức service. Thêm `test/documents-http.int-spec.ts` (guard + multer + LocalFs + Postgres thật): 201 rồi 201 replayed, 200 khi đổi key, 422, 400 không ghi file, 401 trước 400.
- **Thấp:** thêm lọc `tenant_id` tường minh vào mọi truy vấn của service (phòng thủ nhiều lớp, ADR 0003); `@SkipTenantTransaction` đọc cả class (`getAllAndOverride`); test `storage.delete` lỗi không che kết quả.

Còn mở (chấp nhận):
- Key phạm vi tenant, không theo user/route: user thứ hai cùng tenant dùng lại key sẽ nhận document của user đầu (chỉ khi cùng bytes, nếu khác bytes thì 422). Rủi ro thấp, cùng tenant.
- Nhánh phòng thủ ở `documents.controller.ts` (key/user thiếu sau khi file đã ghi) không xoá file; guard làm nó không thể xảy ra.
- "1 job" vẫn chỉ kiểm bằng `created` + audit; test job thật ở T2.4.
