## Cách tự chạy lại

```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm check
pnpm --filter web build
# Kiểm với Keycloak thật (đã chạy 2026-10-18):
pnpm --filter api build
NODE_ENV=development OIDC_ISSUER_URL=http://localhost:8080/realms/invoice \
  DATABASE_URL=postgres://invoice_app:invoice-app-dev-only@localhost:5433/invoice node apps/api/dist/main.js
T=$(curl -s -d grant_type=password -d client_id=dev-cli -d username=consultant@demo.example \
  -d password=demo-dev-only -d 'scope=openid organization:*' \
  http://localhost:8080/realms/invoice/protocol/openid-connect/token | node -pe "JSON.parse(require('fs').readFileSync(0)).access_token")
curl -H "Authorization: Bearer $T" -H "X-Tenant: globex" localhost:3001/auth/me
```

Kết quả đã chạy: không header → 403 `TENANT_REQUIRED`; `acme` → `tenantId ...0a1`; `globex` → `...0a2`; `initech` → 403 `TENANT_NOT_MEMBER`; `admin@acme` gửi `globex` → 403 `TENANT_NOT_MEMBER`; `viewer@globex` không header → 200 (một tenant, quyền chỉ đọc).

**Chưa kiểm bằng trình duyệt thật** (agent không đọc được file env của web): bạn đăng nhập `viewer@globex.example` (thấy 3 mục, không có Tải lên/Thành viên), `admin@acme.example` (thấy đủ 5), `consultant@demo.example` (có dropdown, đổi thì "Mã tổ chức" ở dashboard đổi). Nhớ đăng xuất rồi đăng nhập lại một lần, vì phiên cũ chưa có `tenants`.

## Phương án đã loại

**Đổi tenant bằng đăng nhập lại** với `organization:<alias>` (giữ nguyên T1.2). API không đổi, nhưng mỗi lần đổi phải qua Keycloak, mất trạng thái trang, e2e khó viết, và không có bước "API nhận tenant đã chọn, kiểm membership" như spec/API.md. Cũng đã loại: chép ma trận quyền sang web (hai nguồn sự thật dễ lệch); thay vào đó web hỏi `/auth/me`.

## Code review (subagent code-reviewer)

Không thấy lỗ hổng bypass hay cách ly tenant: header giả, header lặp, `__proto__`, UUID thay alias, CSRF/open redirect ở `/api/tenant` đều bị chặn.

**Đã sửa sau review**
- Người dùng bị 403 vẫn đổi được tenant: nhánh lỗi của `(app)/layout.tsx` giờ hiện `TenantSwitcher` với `session.tenants`.
- Hai nguồn danh sách tenant lệch thứ tự: `tenantsFromClaim` (`auth/tenant.ts`) sắp xếp và bỏ trùng như API.
- Menu mobile không tự đóng: `features/shell/mobile-menu.tsx` đóng khi đổi trang và khi nhấn Escape.
- `data-testid` trùng giữa sidebar và menu mobile: bản mobile dùng tiền tố `mobile-` (T1.8 dùng `nav-*`, `sidebar-nav`).
- Thiếu test `apiGet`: `lib/api.test.ts` (header, cookie giả, không token, 401/403/5xx/mạng). Thêm test header `X-Tenant` lặp ở `jwt-auth.guard.spec.ts`.

**Còn mở (đã ghi "Phát sinh")**
- Vai trò là toàn realm, không theo tenant: user là admin ở acme sẽ giữ quyền admin ở globex. Chấp nhận cho demo (đã ghi ở `permissions.ts`); cần Hậu quyết định trước khi có dữ liệu thật.
- `session.tenants` chỉ đọc lúc đăng nhập, không cập nhật khi refresh token.
- `apiGet` gộp 404/409/422 thành `unavailable` và không parse `Me` bằng schema.
- `returnTo` mất query; `redirect` về login bỏ `callbackUrl`; cookie `tenant` sống 1 năm qua các user cùng trình duyệt.
