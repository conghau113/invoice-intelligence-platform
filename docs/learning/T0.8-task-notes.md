## Phương án đã loại
- Thư viện có sẵn (`markdown-link-check`, `remark-validate-links`): thêm dependency cần duyệt giấy phép, vài cái gọi mạng làm CI chập chờn, và Hậu phải giải thích được code.
- Chạy qua `turbo run`: `turbo.json` đặt `inputs: ["!**/*.md"]`, cache sẽ bỏ qua thay đổi `.md` → xanh giả.
- Fixture tạo trong thư mục tạm (`os.tmpdir()`): SonarCloud hay gắn cờ; dùng fixture commit sẵn + `--root`.
- Dùng `git ls-files` để liệt kê file: cần spawn theo PATH và bỏ sót file chưa add; thay bằng duyệt thư mục bằng `fs`.

## Rủi ro
- **i18n chưa chạy trên dữ liệu thật** (chưa có `messages/`): `check-i18n.mjs:66-97` SKIP khi chưa có next-intl, nghiêm khi có. Bắt bằng fixture `bad-missing`. Còn mở: task i18n M1 phải chạy lại (Phát sinh).
- **Bộ đọc ICU đơn giản** (`check-i18n.mjs:19-34`): chỉ so tham số cấp ngoài, không so tham số lồng trong nhánh plural/select, không hiểu dấu nháy escape `'{'` của ICU. Ví dụ: vi `{n, plural, one {# {name}} other {#}}` so với en thiếu `name` vẫn qua.
- **Slug anchor lệch GitHub**: `check-links.mjs:40-55`. Có test với `#5-cổng-tự-động`; ký tự lạ khác chưa thử.
- **Link ngoài phạm vi kiểm**: reference-style, `<a href>`, `http(s)` (Phát sinh); đích có dấu ngoặc đơn như `foo_(bar).md` bị cắt ở `)` đầu tiên.
- **`SKIP_DIRS` gồm `__fixtures__`** (`check-links.mjs:7`): file `.md` đặt trong thư mục tên đó sẽ không được kiểm.
- **CI chưa chạy thật**: job `repo-checks` chỉ chứng minh được sau khi Hậu push (cục bộ đã chạy từng lệnh).
