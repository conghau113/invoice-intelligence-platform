# M1 — Danh tính, đa tenant, phân quyền, i18n

**Mục tiêu:** Đăng nhập qua Keycloak, dữ liệu tách theo tenant ở tầng DB, phân quyền theo vai trò, đổi vi/en.

**Demo khi xong:** Đăng nhập 2 user ở 2 tenant khác nhau → mỗi người chỉ thấy dữ liệu tenant mình; đổi ngôn ngữ vi/en; viewer không thấy nút ghi.

**Khối lượng:** 9 task, 27 giờ làm task + 9×20 phút cổng hiểu + 2 giờ kiểm tra cuối mốc ≈ **32 giờ**.

Cách chạy một task: xem `docs/plan/WORKFLOW.md`. Ngắn gọn: `/task <ID>` trong Claude Code → đọc diff, chạy thử → `/gate` → cập nhật `TASKS.md` → commit.
