# M2 — Upload, danh sách & lát cắt xuyên suốt bằng XML

**Mục tiêu:** Upload an toàn qua API, hàng đợi, worker gọi dịch vụ AI đường XML (không LLM), hiển thị kết quả — chạy trọn một luồng end-to-end trước khi có LLM.

**Demo khi xong:** Upload một file XML hóa đơn mẫu → trạng thái đổi queued → processing → needs_review → trang chi tiết hiện dữ liệu đã trích xuất (chỉ đọc). Upload trùng không tạo job mới.

**Khối lượng:** 10 task, 27.5 giờ làm task + 10×20 phút cổng hiểu + 2 giờ kiểm tra cuối mốc ≈ **32.8 giờ**.

Cách chạy một task: xem `docs/plan/WORKFLOW.md`. Ngắn gọn: `/task <ID>` trong Claude Code → đọc diff, chạy thử → `/gate` → cập nhật `TASKS.md` → commit.
