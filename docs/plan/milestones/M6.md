### T6.4

**Realtime tiến độ bằng Socket.IO + Redis adapter** · ước tính 4h · phụ thuộc: T3.2, T1.5

**Đọc trước:**
- `docs/architecture/adr/0014-realtime-websocket-vs-fcm.md`

**Yêu cầu:**
- Gateway xác thực JWT khi handshake (web lấy token ngắn hạn từ BFF, ADR 0006); room theo tenant và user
- Worker phát sự kiện tiến độ qua Redis → gateway → client; Redis adapter để chạy nhiều instance
- Client tự kết nối lại; khi mất kết nối thì fallback gọi API lấy trạng thái

**Ngoài phạm vi (KHÔNG làm trong task này):** FCM push (O3)

**Đầu ra:**
- `apps/api/src/modules/realtime/`
- `apps/web/src/features/realtime/`
