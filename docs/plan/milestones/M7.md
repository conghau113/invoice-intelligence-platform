# M7 — Quan sát hệ thống, bảo mật, deploy tự động

**Mục tiêu:** Trace xuyên web → API → worker → AI; dashboard và cảnh báo; CD tự động; checklist bảo mật đạt.

**Demo khi xong:** Mở Grafana: một trace đi qua 4 dịch vụ cho một lần upload; dashboard chi phí LLM; push main → tự deploy.

**Khối lượng:** 7 task, 21.5 giờ làm task + 7×20 phút cổng hiểu + 2 giờ kiểm tra cuối mốc ≈ **25.8 giờ**.

Cách chạy một task: xem `docs/plan/WORKFLOW.md`. Ngắn gọn: `/task <ID>` trong Claude Code → đọc diff, chạy thử → `/gate` → cập nhật `TASKS.md` → commit.
