# M5 — Hỏi đáp RAG có trích dẫn

**Mục tiêu:** Hỏi bằng tiếng Việt/Anh về hóa đơn của tenant, câu trả lời có trích dẫn nguồn, không rò dữ liệu chéo tenant.

**Demo khi xong:** Hỏi 'Tháng 9 chi bao nhiêu cho nhà cung cấp X?' → câu trả lời có số liệu tính bằng SQL + trích dẫn hóa đơn, bấm vào mở tài liệu.

**Khối lượng:** 7 task, 22 giờ làm task + 7×20 phút cổng hiểu + 2 giờ kiểm tra cuối mốc ≈ **26.3 giờ**.

Cách chạy một task: xem `docs/plan/WORKFLOW.md`. Ngắn gọn: `/task <ID>` trong Claude Code → đọc diff, chạy thử → `/gate` → cập nhật `TASKS.md` → commit.
