# M0 — Nền móng repo & công cụ

**Mục tiêu:** Monorepo chạy được bằng một lệnh, CI xanh, Claude Code đọc hiểu dự án.

**Demo khi xong:** `docker compose up` + `pnpm dev` → 3 dịch vụ trả về health OK; push lên GitHub → CI xanh.

**Khối lượng:** 10 task, 19.5 giờ làm task + 10×20 phút cổng hiểu + 2 giờ kiểm tra cuối mốc ≈ **24.8 giờ**.

Cách chạy một task: xem `docs/plan/WORKFLOW.md`. Ngắn gọn: `/task <ID>` trong Claude Code → đọc diff, chạy thử → `/gate` → cập nhật `TASKS.md` → commit.
