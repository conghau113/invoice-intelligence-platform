# M3 — AI trích xuất PDF/ảnh & form kiểm tra

**Mục tiêu:** Thêm đường LLM cho PDF/ảnh vào lát cắt đã chạy; người dùng xem, sửa, duyệt trên form.

**Demo khi xong:** Upload PDF hóa đơn → vài giây sau form tự điền, field độ tin cậy thấp được tô vàng, sửa và duyệt.

**Khối lượng:** 8 task, 22.5 giờ làm task + 8×20 phút cổng hiểu + 2 giờ kiểm tra cuối mốc ≈ **27 giờ**.

Cách chạy một task: xem `docs/plan/WORKFLOW.md`. Ngắn gọn: `/task <ID>` trong Claude Code → đọc diff, chạy thử → `/gate` → cập nhật `TASKS.md` → commit.

**Yêu cầu:**
- `POST /documents/:id/reopen`, quyền `document:approve`, `If-Match` bắt buộc; `approved → needs_review`, version + 1, đi qua `DocumentStateMachine`, ghi audit (chỉ id và số)
