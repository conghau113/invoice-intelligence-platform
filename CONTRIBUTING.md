# Contributing

## Commit convention (Conventional Commits)

Format: `<type>(<scope>): <summary>` — scope is usually the task ID.

Types: `feat`, `fix`, `docs`, `chore`, `test`, `refactor`, `perf`, `ci`.

Examples: `feat(T0.2): scaffold apps/web`, `docs(T0.1): update ledger`.

Never commit secrets or real invoice data (see `docs/LEGAL.md`).
